8. PMD for Apex Static Code Analysis | Robert Söesemann

Robert Söesemann ported PMD, a static code analyzer, to the Salesforce world. He teaches me what this is all about. This talk is a continuation from the last episode.

Main Points

  1. How PMD works
  2. What is PMD for Apex
  3. Out-of-the-box rules
  4. Code formatting check in PMD for Apex
  5. Integration of PMD into various IDEs and CI-platforms
  6. How to get started
  7. Ways to customize and create new rules
  8. Contribute to the PMD open source repo
  9. Clean code with PMD as a Trailhead topic
